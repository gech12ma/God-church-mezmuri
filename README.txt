GOD CHURCH MEZMUR DEBTER — FIRST VERSION

Included:
- Amharic interface
- Add, edit and delete mezmur lyrics
- Search titles and lyrics
- Categories: worship, praise, other
- Favorites
- Offline cache after first successful load
- Songs stored locally on the current device/browser

IMPORTANT LIMITATION:
This version does NOT sync songs between members' phones. Each phone has its own local list. A later version can add a shared database and member accounts.

ANDROID SETUP (simple route):
1. Keep this ZIP file and extract it using your phone's Files app.
2. The app is a small website (index.html + manifest.json + sw.js).
3. To get reliable offline/PWA installation, the files must be hosted on an HTTPS website.
4. A church adult/authorized representative can publish the folder using a trusted static hosting service, or a developer can host it for the church.
5. Open the HTTPS address in Chrome on Android. Load it once while online.
6. In Chrome, tap ⋮ > Add to Home screen (or Install app, if shown).
7. Open it from the home screen. After the first successful load, the shell can open offline.

TESTING WITHOUT HOSTING:
Open index.html from the extracted folder in a browser. Adding/searching/favorites work in that browser, but offline app installation/service-worker caching may not work from a file:// address.

DATA WARNING:
Clearing Chrome site data can remove locally stored songs. Export/backup and shared cloud sync are not included in this first version. Do not enter private information.

CONTENT RIGHTS:
Only enter lyrics or recordings that the church owns or has permission to use.
